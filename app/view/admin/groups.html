为什么余额要自己记账？ 实测两家上游都没有「用 API Key 读余额」的接口（硅基流动的余额接口已下线、 TierFlow 的余额要控制台登录态），所以本站按每次调用的真实用量累加成本， 再用「你录入的额度 − 已用」算出剩余。顺带得到一个上游给不了的数字：消耗速率。
对账按钮会读上游自己记的累计用量（TierFlow 有、硅基流动没有）。 它不参与余额计算，只用来验证我们的计价口径对不对。 若差额较大，通常是两件事：单价/时段配错了，或上游用的是美元口径（需按汇率换算）。
