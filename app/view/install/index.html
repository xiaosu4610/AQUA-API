确实要重装怎么办？安装锁定有两道判断，缺一不可：
① 锁文件 runtime/install.lock；② 数据库里已有表结构与管理员记录。
也就是说，只删锁文件是重装不了的 —— 还必须清空数据库（SQLite 删掉 runtime/aqua.sqlite；MySQL 删库重建）。这个双重保险是刻意设计的：
否则一次误操作就能把线上站点的配置清空。
另外，装好之后建议把 install 相关代码从生产环境移除（或在 Nginx 层屏蔽 /install），这是纵深防御的常规做法。
