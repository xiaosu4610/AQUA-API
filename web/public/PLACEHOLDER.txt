==========

用途说明：

Go 后端通过 `//go:embed web/dist` 把前端构建产物嵌入二进制。
`go:embed` 在编译期若发现目标目录没有任何可嵌入文件，会直接编译失败。

而前端构建产物（web/dist/*）按设计不入库（原因见 web/.gitignore），
于是全新克隆的仓库里 web/dist 目录会是"空"的，导致 `go build` 失败。

保留本文件即可让 `go build` 在未构建前端时依旧通过。

----------------
正确使用方式
----------------

本地开发 / 部署前必须先构建前端：

    cd web
    npm install
    npm run build      # 生成 dist/index.html 与 dist/assets/*

随后执行 `go build ./cmd/aqua`，前端产物会被一并嵌入。

若忘记构建，后端启动后访问首页会返回明确提示（而不是空白页或 500），
按提示执行上面的构建命令即可。
